# Environmental Specification: Line 2 Operating Envelopes

Document ID: `environmental-spec-operating-envelopes`
Area: Facilities engineering
Applies to: `cnc-line-2`, `cnc-line-2-cnc-04`
Revision: 2026-05-15

## Scope

This specification defines the environmental conditions required for stable machining on line 2 CNC assets. It covers shop-floor ambient conditions, HVAC alarms, vibration exposure, compressed-air supply, and coolant/chiller operating limits.

## Operating envelopes

| Condition | Normal operating range | Investigation threshold |
|---|---:|---:|
| Ambient temperature near CNC-04 | 19.0 C to 25.0 C | Above 27.0 C for more than 20 minutes |
| Relative humidity near CNC-04 | 35% to 60% RH | Below 30% RH or above 65% RH for more than 30 minutes |
| Floor vibration at CNC-04 | Below 2.5 mm/s RMS | Above 4.0 mm/s RMS sustained for more than 10 minutes |
| Compressed-air header pressure | 6.1 bar to 6.8 bar | Below 5.8 bar for more than 5 minutes |
| CNC coolant supply temperature | 20.0 C to 23.0 C | Above 25.0 C or below 18.0 C |
| Chiller return temperature delta | 1.0 C to 2.5 C | Above 3.5 C |

## RCA guidance

Environmental causes should be treated as supported only when a threshold excursion aligns with the incident timing and affected asset. Isolated readings inside the normal operating range should not be treated as causal.

When readings are relevant but remain inside the operating envelopes, the environmental investigator should cite this specification and the matching readings as negative evidence.
